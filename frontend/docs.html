Sanatan API Documentation

Fetch Shloks from the Bhagavad Gita (701 verses, 18 chapters) and the four Vedas (10,552 Rigveda mantras live) as clean JSON.

Introduction

The Sanatan API is a REST interface to Vedic scripture. Every verse is returned with its original Devanagari text, a romanised transliteration, and Hindi & English meaning — so you can render it faithfully in any app, bot, or website.

Base URL

All endpoints are relative to:

BASEhttps://sanatan-api.antideploy.app/api/v1

Authentication

Authenticate every request with your API key in the x-api-key header. Generate keys from the API Keys page.

HEADERx-api-key: sanatan-xxxxxxxxxxxx
terminal
curl https://sanatan-api.antideploy.app/api/v1/gita/chapters/2/verses/47 \
  -H "x-api-key: {{API_KEY}}"
fetch.js
const res = await fetch(
  "https://sanatan-api.antideploy.app/api/v1/gita/chapters/2/verses/47",
  { headers: { "x-api-key": "{{API_KEY}}" } }
);
const data = await res.json();
console.log(data);
request.py
import requests

res = requests.get(
    "https://sanatan-api.antideploy.app/api/v1/gita/chapters/2/verses/47",
    headers={"x-api-key": "{{API_KEY}}"},
)
print(res.json())

Rate limits

The free tier allows 1,000 requests per month at up to 10 requests/second. Every response carries headers telling you where you stand:

HEADERX-RateLimit-Limit: 1000
HEADERX-RateLimit-Remaining: 987
HEADERX-RateLimit-Reset: 1735689600

Exceeding the limit returns 429 Too Many Requests.

Bhagavad Gita

701 verses across 18 chapters. Chapter objects carry English + Sanskrit names with EN/HI meaning and summary:

gita
# All chapters (id, eng_name, sanskrit_name, meaning, summary, verses_count, verses_available)
GET /gita/chapters

# Chapter 2 with all 72 verses
GET /gita/chapters/2

# A single verse
GET /gita/chapters/2/verses/47

# A random verse
GET /gita/random
terminal
# A random shlok
curl https://sanatan-api.antideploy.app/api/v1/gita/random \
  -H "x-api-key: {{API_KEY}}"
gita.js
const r = await fetch("https://sanatan-api.antideploy.app/api/v1/gita/chapters/2", {
  headers: { "x-api-key": "{{API_KEY}}" },
});
const chapter = await r.json();
gita.py
res = requests.get(
    "https://sanatan-api.antideploy.app/api/v1/gita/random",
    headers={"x-api-key": "{{API_KEY}}"},
)
shlok = res.json()

Vedas

One lean table per Veda (rigveda | yajurveda | samaveda | atharvaveda). The list carries metadata with canonical totals vs actually loaded counts; browse pages with limit (default 50, max 200) and offset.

vedas
# All Vedas (eng_name, sanskrit_name, description{en,hi}, total_mantras, mantras_available)
GET /vedas

# First 10 Rigveda mantras
GET /vedas/rigveda?limit=10

# Next page
GET /vedas/rigveda?limit=10&offset=10

# A specific mantra (Rigveda 3.62.10 — Gayatri)
GET /vedas/rigveda/mandala/3/sukta/62/mantra/10

Search

Search across Sanskrit, transliteration, and Hindi/English translations in the Gita and all Veda tables at once. limit defaults to 20, max 50.

terminal
curl "https://sanatan-api.antideploy.app/api/v1/search?q=agni" \
  -H "x-api-key: {{API_KEY}}"

Errors

401Missing or malformed x-api-key / Invalid API key
403No API key found. Create an API key to use. (revoked key)
404Chapter / verse / Veda / mantra not found
429Rate limit exceeded (requests/second) / Monthly quota exceeded

Errors return { "error": "message" } with the matching HTTP status.
