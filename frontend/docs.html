Sanatan API Documentation

Fetch Shloks from the Bhagavad Gita and all four Vedas as clean JSON.

Introduction

The Sanatan API is a REST interface to Vedic scripture. Every verse is returned with its original Devanagari text, a romanised transliteration, and Hindi & English meaning — so you can render it faithfully in any app, bot, or website.

Base URL

All endpoints are relative to:

BASEhttps://yourdomain.com/api/v1

Authentication

Authenticate every request with your API key in the x-api-key header. Generate keys from the API Keys page.

HEADERx-api-key: sanatan-xxxxxxxxxxxx
terminal
curl https://yourdomain.com/api/v1/gita/chapter/2/verse/47 \
  -H "x-api-key: {{API_KEY}}"
fetch.js
const res = await fetch(
  "https://yourdomain.com/api/v1/gita/chapter/2/verse/47",
  { headers: { "x-api-key": "{{API_KEY}}" } }
);
const data = await res.json();
console.log(data);
request.py
import requests

res = requests.get(
    "https://yourdomain.com/api/v1/gita/chapter/2/verse/47",
    headers={"x-api-key": "{{API_KEY}}"},
)
print(res.json())

Rate limits

The free tier allows 1,000 requests per month at up to 10 requests/second. Every response carries headers telling you where you stand:

HEADERX-RateLimit-Limit: 1000
HEADERX-RateLimit-Remaining: 987
HEADERX-RateLimit-Reset: 1735689600

Exceeding the limit returns 429 Too Many Requests.

Bhagavad Gita

List all 18 chapters, or fetch a chapter and its verses.

terminal
# A random shlok
curl https://yourdomain.com/api/v1/gita/random \
  -H "x-api-key: {{API_KEY}}"
gita.js
const r = await fetch("https://yourdomain.com/api/v1/gita/chapters/2", {
  headers: { "x-api-key": "{{API_KEY}}" },
});
const chapter = await r.json();
gita.py
res = requests.get(
    "https://yourdomain.com/api/v1/gita/random",
    headers={"x-api-key": "{{API_KEY}}"},
)
shlok = res.json()

Vedas

Browse a Veda, or drill down to a specific mantra by mandala / sukta / mantra.

vedas
# List all Vedas
GET /vedas

# One Veda
GET /vedas/rigveda

# A specific mantra
GET /vedas/rigveda/mandala/1/sukta/1/mantra/1

Search

Full-text search across Sanskrit, transliteration, and translations.

terminal
curl "https://yourdomain.com/api/v1/search?q=agni" \
  -H "x-api-key: {{API_KEY}}"

Standard response format

response.json
{
  "id": "gita_2_47",
  "source": "Bhagavad Gita",
  "sanskrit": "कर्मण्येवाधिकारस्ते...",
  "transliteration": "karmanyevadhikaraste...",
  "translations": { "hindi": "...", "english": "..." },
  "meaning": "..."
}

Errors

401Missing or invalid API key
403No API key found. Create an API key to use.
404Verse or chapter not found
429Rate limit exceeded

Errors return { "error": "message" } with the matching HTTP status.
